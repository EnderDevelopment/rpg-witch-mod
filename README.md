# RPG Witch Mod

Enhance your Minecraft experience with an RPG Witch mod featuring spells, items, and entities.

## Features

- Adds a Witch Staff item for casting spells
- Includes Fireball and Heal spells
- Features a Witch Altar block
- Adds a Witch entity with custom attributes

## Requirements

- Minecraft Forge
- Minecraft 1.18.2 or later

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

- Craft the Witch Staff to cast spells.
- Place the Witch Altar block to summon witches.
- Encounter witches in the world and interact with them.

The mod does not have a configuration file. All settings are hardcoded in the mod.
